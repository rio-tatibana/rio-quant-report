# rioの勝手にクオンツ分析

米国個別株のクオンツ分析メディア用・静的ホームページの初期版です。

## ファイル
- `index.html` — ホームページ本体
- `style.css` — デザイン
- `script.js` — 検索モーダル等の簡単な動作

## ローカルでの起動・検証方法
ブラウザのCORS制限を回避してローカルで安全に動作確認を行うため、プロジェクトのルートディレクトリでPython簡易サーバーを起動します。

1. プロジェクトのルート（`e:\riowork\SNSdata\`）でターミナルを開きます。
2. 以下のコマンドを実行して簡易サーバーを起動します。
   ```bash
   python -m http.server 8000
   ```
3. ブラウザで以下のURLにアクセスします。
   ```text
   http://localhost:8000/rio_quant_homepage/
   ```

## 公開
GitHub Pages等で公開できます。`index.html`をリポジトリのトップに置いてください。

現在表示している株価・ランキング値は、`data/stocks.json`から非同期でロードされます。実運用では株価API・財務データAPI等を接続して、最新値に自動で差し替える想定です。
